# Data Analytics Projects

Welcome to my project portfolio. This repository contains practical projects focused on data analysis, business insights, and reporting.

## Projects

### E-Commerce Customer Analytics
**Tools:** Python, Pandas, NumPy, Matplotlib, SQL, Power BI

An end-to-end analytics project covering synthetic transaction data generation, data cleaning, sales KPIs, monthly trends, category and product performance, customer segmentation, repeat purchasing, SQL queries, and Power BI starter measures.

- [Open project README](ecommerce-customer-analytics/README.md)
- [Python source code](ecommerce-customer-analytics/src/)
- [SQL analysis queries](ecommerce-customer-analytics/sql/analysis_queries.sql)
- [Power BI DAX measures](ecommerce-customer-analytics/powerbi/measures.dax)
- [Portfolio case study](ecommerce-customer-analytics/reports/portfolio_case_study.md)
- [Resume and LinkedIn wording](ecommerce-customer-analytics/reports/resume_and_linkedin.md)

> **Data note:** The project uses synthetic data for portfolio demonstration. It does not represent real company data or measured business results.

## Run the project

Open the project folder and follow the setup instructions in its README. The scripts generate the data and output reports locally. Generated datasets, charts, and the local SQLite database can be recreated; no ZIP archive is needed.
